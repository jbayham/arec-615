Why does backward induction save work?

The full tree contains 35 complete feasible extraction sequences and 56 nodes. But many nodes have the same stock at the same date. They share the same continuation problem, regardless of how we reached them.

Merging these duplicates leaves 16 reachable date–stock pairs. We solve each pair once, then reuse its value. Earlier profits can differ across paths; the best remaining payoff from an identical state and date does not.
